# Game Design

## 題材選定

ゲーム化は、反復学習、分類、順序、判断、探索、チーム交流に価値がある場合に使う。単なる文書閲覧、専門家の最終判断、個人評価はゲーム化しない。

## 設計項目

- 学習・業務上の目標
- 対象プレイヤーと前提知識
- 1回のプレイ時間とセッション数
- コアループ: 観察 → 選択 → 即時フィードバック → 次の挑戦
- 勝敗・完了条件
- 難易度曲線とヒント
- 正解の根拠と解説
- 再挑戦時の変化
- アクセシビリティと失敗時の救済

## 方式

- クイズ: 知識確認。暗記だけにせず解説を付ける。
- 分類・マッチング: 概念と事例の対応。
- 並べ替え: プロセスや優先順位。
- 探索: 情報発見と状況理解。
- シミュレーション: 複数選択の影響比較。正解が一つでない場合に適する。

得点だけを目的にせず、誤答から学べるフィードバックを中心にする。
