# Deal Briefing セクション

当日または次の就業日に予定された顧客商談がある場合だけ実行する。

## 収集

1. 予定表から対象会議を特定し、内部準備会議ではなく顧客参加の本番会議を優先する。
2. 顧客名・商談名で関連メール、Teams、SharePoint、OneDriveを検索する。
3. 主要メール、提案資料、過去議事録、許可された会議トランスクリプトから最新情報を取得する。
4. 必要な場合だけ参加者の役職・所属を確認する。

## セクション構成

```markdown
## 💼 Deal Briefing — <商談名>

### 商談概要
<日時、場所、目的、背景、期待成果>

### 顧客・参加者
<確認済みの企業情報と参加者の役割>

### 戦略と進め方
<推奨アジェンダ、訴求価値、会話のフック>

### 想定Q&A・リスク
<仮説であることを明示した質問、回答方針、対策>

### 次アクション
<期限付きTo-Doと成功基準>
```

固有名詞、数値、日付、引用は取得元に基づく。仮説は事実と分ける。機微なM&A、人事、未公開財務を直接引用しない。同じ商談の前回配信がある場合は全文を繰り返さず、変更点と当日必要な準備だけを載せる。
