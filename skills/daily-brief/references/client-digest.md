# Client Intelligence セクション

設定された曜日、または直近に重要な顧客接点がある場合だけ実行する。通常は週1回を推奨する。

## 収集

1. 過去14日の予定表、許可された会議トランスクリプト、議事録、外部ドメインとのメールから顧客候補を抽出する。
2. 実行ユーザーの組織ドメインを確認し、社内参加者だけの会議を除外する。
3. 会社名の表記揺れを正規化し、接点の頻度と新しさから最大5社に絞る。
4. 各社について直近6か月の公開情報から、AI活用、業務変革、投資動向を調べる。一次情報を優先する。

## セクション構成

```markdown
## 🏢 Client Intelligence

### <会社名> — <業界・直近接点>
- 🤖 AI活用: <新しい公開情報と出典>
- 🔄 業務変革: <新しい公開情報と出典>
- 💰 投資動向: <新しい公開情報と出典>
- 💡 商談への示唆: <役割ベースの提案>
```

前回配信と同じ公開情報や顧客説明は繰り返さず、差分だけを載せる。十分な公開情報がなければ「直近の公開情報なし」とする。社内議事録の金額、未公開計画、個人情報は本文やWeb検索へ出さない。実在の同僚へ勝手にタスクを割り当てない。
