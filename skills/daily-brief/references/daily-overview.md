# Daily Overview セクション

本人向けの日次概要を、利用者のタイムゾーンに基づいて作る。

## 収集

- プロフィールから本人の宛先とマネージャーを確認する。
- 当日0:00〜23:59の予定を取得し、現在時刻以降の会議を中心に扱う。
- 前就業日以降の未読・フラグ付きメール、Teamsの本人宛メンション、関連文書を必要最小限で検索する。
- 月曜日は原則として前週金曜日まで広げる。取得できる場合は休日表を使い、前就業日を調整する。

## 構成

```markdown
## ☀️ 1日の概要
<直近会議、重複、返答要件、マネージャー関連を事実だけで2〜4文>

## 📨 前回配信以降の主な更新
<新規または未処理の差分。なければ明記>

## ✅ 今日のおすすめタスク
<未完了と確認できたタスク、質問、判断事項。期限と出典を付ける>

## 📅 今日の会議準備
| 時間 | タイトル | 主催者 | 概要 | 準備内容 |
|---|---|---|---|---|
```

キャンセル済み会議は除外する。非公開予定は時間帯だけを記載する。会議重複、未返答、仮承諾は注意点として明示する。過去の会話と台帳にある解決済みタスクや既配信メッセージは繰り返さない。
