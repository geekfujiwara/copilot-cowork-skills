# Session Prep Edge Cases

## 同梱アセットを前提にしない

参照する台本テンプレート、実績一覧、写真などは使用前に実在を確認する。見つからない場合は作成可能な範囲を示し、必要な箇所を `[要確認]` とする。

## 大容量または添付PPTX

ファイル読取機能が返すローカルパスを使う。`python-pptx`へ渡す場合は解決済みパスを使い、`scripts/extract-deck-text.py`でスライド範囲を分けて抽出できる。本文だけでなく表とノートも確認する。

## 素材が見つからない

内容を捏造せず、必要な一次情報、再添付、アクセス権の確認を利用者へ依頼する。公開情報で内部資料を代用した場合は、その違いを明示する。

## 依頼内容が途中で変わる

割当時間、対象者、提出物、期限は最新の明示的な合意を採用する。矛盾する情報がある場合は、台本を作る前にまとめて確認する。

## 返信下書きが既にある

既存下書きの宛先、更新日時、件名を確認し、重複作成または重複送信を避ける。破棄や上書きは利用者が決める。

## プロフィールや写真がない

氏名、組織、経歴、写真を推測しない。利用者が指定した公開可能な最新版だけを使う。
