# セッション台本テンプレート

プレースホルダーを確認済み情報で置換し、時間の合計を検算する。

```markdown
# {{タイトル}}

| 項目 | 内容 |
|---|---|
| イベント | {{イベント名}} |
| 日時・枠 | {{日時}}／約{{合計時間}}分 |
| 対象 | {{聴衆}} |
| 登壇者 | {{氏名}}／{{所属}} |
| ねらい | {{持ち帰ってほしいこと}} |
| 元資料 | {{資料名と出典}} |

## 核となるメッセージ
> {{1つに絞ったメッセージ}}

## 全体タイムライン
| # | 時間 | パート | 目的 |
|---|---|---|---|
| 1 | {{開始}}–{{終了}}分 | {{パート}} | {{目的}} |

## パート別台本
### {{パート名}}（{{開始}}–{{終了}}分）
- ねらい: {{目的}}
- トーク: {{話し言葉の原稿}}
- スライド／画面: {{見せるもの}}
- デモ手順: {{番号付き手順}}
- 失敗時の代替: {{フォールバック}}

## 事前準備
- [ ] {{デモ環境}}
- [ ] {{数値と出典}}
- [ ] {{他登壇との重複}}

## 会場・運営メモ
- {{設備、聴衆、進行上の注意}}

## 時間超過時の割愛順
1. {{最初に削る内容}}

## 出典・素材
- {{一次情報と利用条件}}
```

核メッセージは1つに絞り、トークは読み上げ可能な言葉にする。デモや数値の一次情報がない箇所は `[要確認]` を残す。
