# Analysis Patterns

- **記述**: 件数、割合、分位点、代表値、分布。偏りが大きい場合は平均だけを使わない。
- **比較**: 属性、地域、製品、期間を同じ母数・定義で比較し、絶対数と構成比を併記する。
- **時系列**: 欠損期間、季節性、定義変更を確認し、途中期間と完了期間を直接比較しない。
- **ファネル・継続**: 各段階の条件と分母を固定し、離脱を示す。
- **セグメント・コホート**: 目的に関係する特徴だけを使い、各群の件数を示す。
- **関係性**: 交絡、選択バイアス、逆因果を確認し、原因と断定しない。
- **異常**: 入力誤り、重複、単位違い、実際の異常を分ける。
- **文書**: テーマ、感情、依頼、リスク、根拠へ分類し、個人を特定する引用を避ける。
