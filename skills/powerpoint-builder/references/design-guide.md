# Presentation Design Guide

## Story first

- 結論、背景、根拠、選択肢、推奨、次の行動を一つの流れにする。
- 1スライド1メッセージとし、タイトルだけで要点が分かるようにする。
- 読者の判断に不要な情報は本文ではなく付録へ移す。
- データ、引用、推論、提案を区別し、図表には単位、期間、母数、出典を付ける。

## Layout

- ワイド画面では左右に0.5インチ以上の余白を確保する。
- 本文は原則14pt以上、タイトルは28pt以上を目安とする。
- 本文段落を中央揃えにせず、比較、表、カード、プロセス、タイムラインを用途に応じて使う。
- すべてのスライドに意味のある視覚要素を置くが、装飾だけの図形を増やさない。
- 同種要素の幅、高さ、間隔、揃えを統一する。
- タイトル下の飾り線など、内容に関係しない定型装飾へ依存しない。

## Color and typography

テーマとブランド規定から主色、補助色、アクセントを選ぶ。指定がなければ、1つの主色を画面の60〜70%に使い、補助色1〜2色とアクセント1色に絞る。色だけで状態を伝えず、ラベルや記号を併記する。

日本語を含む場合は日本語グリフを持つ利用可能なフォントを使う。利用環境にないフォントを埋め込まない。コードまたは数値以外で等幅フォントを多用しない。

## Recommended slide patterns

- 表紙: 主張、サブタイトル、日付、確認済み著者情報
- エグゼクティブサマリー: 主要結論3点と推奨
- 大きな数値: KPIと定義、比較対象、期間
- 比較: 2列または3列で共通軸を揃える
- プロセス: 3〜6段階と各段階の成果
- タイムライン: 日付、マイルストーン、責任者
- アーキテクチャ: 境界、方向、責任範囲、凡例
- 次の行動: アクション、責任者、期限、依存関係
- 出典: 発行元、資料名、公開日、URLまたは内部参照

## Accessibility

- 背景と本文のコントラストを確保する。
- 画像または複雑な図には説明を付ける。
- 読み順を左上から右下へ自然にする。
- 小さな脚注へ重要事項を隠さない。
- 赤と緑だけで差を表現しない。
