# Success Example Selection

## 成功事例の最低条件

事例には、対象、実施内容、結果を確認できる証拠が必要である。利用率、売上、時間短縮、品質、満足度、リスク低減、期限達成など、目的に対応した結果を優先する。

「成功」「好評」「代表事例」という表現、受賞、掲載、主観的な称賛だけでは成功の証拠にならない。

## 比較可能性

候補ごとに次を確認する。

- 目的と対象利用者
- 規模、地域、業務領域
- 技術・運用環境
- 制約と依存関係
- 意思決定または実施の段階
- 成果指標と測定期間

完全一致は要求しない。異なる条件と、そのため転用できない要素を明記する。

## 転用方法

成果物の表面をコピーするのではなく、成功につながった判断基準、順序、統制、測定方法を抽出する。対象への適用は `そのまま適用`、`条件付きで適用`、`参考のみ` に分ける。

## 証拠の優先順位

1. 確認済みの組織内成果データ
2. 承認済みの事例資料と意思決定記録
3. 一次情報を伴う公開事例
4. 二次情報

適切な事例が1件しかない場合は1件だけ使用する。見つからない場合は、成功事例比較を実施できなかったことをレポートに示す。
