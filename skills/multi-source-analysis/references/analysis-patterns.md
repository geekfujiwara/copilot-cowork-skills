# Analysis Patterns

## 記述

件数、割合、最小、最大、中央値、平均、分位点、分布を確認する。偏りが大きい場合は平均だけを代表値にしない。

## 比較

属性、地域、製品、チャネル、期間などを同じ母数・定義で比較する。構成比と絶対数を併記し、小集団は統合または非表示にする。

## 時系列

粒度、欠損期間、季節性、定義変更を確認してから増減率、移動平均、目標差、変化点を計算する。途中期間と完了期間を直接比較しない。

## ファネル・継続

各段階の対象条件と分母を固定し、段階間の離脱を示す。登録、参加、行動、成果など、イベント分析にも利用できる。

## セグメント・コホート

分析目的に関係する特徴だけを使う。後付けで都合のよい区切りを量産せず、各群の件数と定義を示す。

## 関係性と寄与候補

散布、クロス集計、相関などで候補を探す。交絡、選択バイアス、逆因果を確認し、実験または追加検証なしに原因と断定しない。

## 異常と外れ値

入力誤り、重複、単位違い、実際の異常を分ける。除外する場合は閾値、理由、除外前後の結果を示す。

## 自由記述・文書

発言や文書をテーマ、感情、依頼、リスク、根拠へ分類する。代表例は短く引用し、件数と分類規則を示す。個人を特定できる引用を避ける。
