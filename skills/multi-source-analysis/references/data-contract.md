# Data Contract

分析前にソースごとに次を記録する。

| 項目 | 内容 |
|---|---|
| ソース | ファイル、表、シート、リスト、会話など |
| 所有者・更新日時 | 鮮度と責任範囲 |
| 分析単位 | 1行が表す対象 |
| 主キー・結合キー | 一意性、表記揺れ、未結合の扱い |
| 対象期間・タイムゾーン | 開始、終了、基準日時 |
| 列定義 | 意味、型、単位、許容値 |
| 欠損・重複 | 判定条件と処理方針 |
| 除外 | 条件、理由、影響件数 |
| 機密区分 | 個人情報、匿名化、公開範囲 |

## 統合ルール

- 同名列を同義とみなさず、定義と単位を比較する。
- 名前の曖昧一致だけで結合せず、確認済みキーまたは対応表を使う。
- 多対多結合は行数を増幅するため、結合前後の件数とキー重複を確認する。
- 欠損をゼロ、未参加、不成功へ自動変換しない。
- 原値、変換後の値、変換規則を追跡できるようにする。
