# 任意の拡張処理

必要な場合だけ実施する。取得対象、出力先、保持期間を先に確認し、個人データを最小化する。

## 採点集計

採点アンケートを取得し、同梱の `aggregate_scoring.py` に投票者区分、選択肢、重みを引数で渡す。フォーム外の票を追加する場合は、根拠と追加件数を Fact Markdown に記録する。集計前後の総票数を照合する。

## 会議チャットの画像

対象会議のチャット ID をツールから取得し、必要な期間のメッセージだけを読む。`extract_chat_image_refs.py` で画像参照を抽出し、取得権限がある画像だけを `output/images/` へ保存する。投稿者名をファイル名に含めない。

## 会場写真

利用者が指定した保存場所から、掲載許可が確認できる写真だけを取得する。顔、名札、画面、ホワイトボードなどに個人情報や機密情報が写っていないか確認する。外部公開可否が不明な写真はレポートへ含めない。

## 自由記述アンケート

原文の再掲は既定で行わない。集計または匿名化した要約を優先し、少人数属性との組み合わせで個人を再識別できる分類を避ける。原文が必要な場合は、利用目的、閲覧者、保存期間について明示的な承認を得る。

## 失敗時

権限不足、ページング、破損した入力、欠損列への対処は `troubleshooting.md` を参照する。確認できない値は補完せず、欠損として記録する。
