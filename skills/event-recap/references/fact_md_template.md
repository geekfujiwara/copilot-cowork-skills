# Fact MD テンプレート（章立て）

`output/{EVENT_NAME}_ファクトシート.md` を作る際の標準構成。`{...}` はプレースホルダー。
HTML レポートはこの MD の章を要約・転記して作る。

```markdown
# {EVENT_NAME} — 開催ファクトシート

> 本ドキュメントは、社内レポートおよび公開ブログの素材とするための一次ファクト集（FACT）です。
> 出典：当日資料 `{SOURCE_FILE}`、参加者データ `{DATA_SOURCE}`（{N}件）、イベント情報 `{EVENT_NAME}`。
> 集計基準日：{TODAY}

## 1. イベント概要（5W1H）
| 項目 | 内容 |
|---|---|
| 名称 | {EVENT_NAME}（{HASHTAG}） |
| 主催 | {ORGANIZER} |
| 開催日 | {EVENT_DATE} |
| 時間 | {START}–{END} |
| 形式 | {FORMAT}（オンサイト{拠点} ＋ オンライン 等） |
| 目的 | {PURPOSE} |
（主要人物：大将／司会／締め 挨拶 など）

## 2. 当日プログラム（タイムテーブル）
| 時刻 | 内容 | 概要 |
（当日資料 PPTX のタイムテーブルとノートから）

## 3. 競技/セッション結果
（対抗戦なら総合得点・優勝・上位チーム。一般イベントならセッション一覧・登壇者）

## 4. 重要KPI（提案・集計）
> 母数の定義を明示（例: 登録リスト {N} 件、{ATTEND_FIELD}=true）。
（KPI①参加規模・チャネル ②参加企業 ③役職/ロール ④エンゲージメント ⑤軍別バランス）
（比率・合計は aggregate_records.py の出力値を使用）
（末尾に「今後トラッキング推奨 KPI」）

## 5. 協賛・スペシャルサンクス
（スポンサー、参加賞、ノベルティ）

## 6. 運営上の取り決め・広報ポリシー（記事化時の注意）
（SNS 可否、写真/スクショ/社名の扱い、ハッシュタグ、被写体同意）

## 7. 関連リンク・素材
| 区分 | リンク |
（当日資料 / 参加者データ / 写真フォルダ / アンケート / コミュニティ）

### 注記（データの前提）
（登録ベースと実参加の差、招待者数とリスト件数の別、企業名正規化の方法、一次情報の所在）
```

## 必須の作法
- **出典と集計基準日**を冒頭に置く。
- **データ前提の注記**を必ず入れる（誠実性：登録 vs 実参加、招待者数との区別、自社スタッフ未登録など）。
- 数値は手計算せず `aggregate_records.py` の出力を転記。
- 公開ブログ素材化を見据え、**広報ポリシー章**を必ず設ける。
